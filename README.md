# Geometrical-Form-Ripper

This is a school project written in Python that allows users to calculate the perimeter and area of various geometric shapes. The program supports both English and Turkish languages.

## Features

- Calculate the perimeter and area of squares, rectangles, circles, and triangles.
- Multi-language support (English and Turkish).
- User-friendly command-line interface.


## Installation

1. Clone the repository:
    ```sh
    git clone https://github.com/yourusername/Geometrical-Form-Ripper.git
    ```
2. Navigate to the project directory:
    ```sh
    cd Geometrical-Form-Ripper
    ```

## Usage

1. Run the main script:
    ```sh
    python src/main.py
    ```
2. Follow the on-screen instructions to choose your language and calculate the perimeter and area of the desired geometric shapes.
